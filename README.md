# 闲鱼机会雷达

面向闲鱼卖家的轻量选品 Chrome 扩展 MVP。它把需求、竞争、利润、交付和合规风险放进一张机会卡，帮助用户先验证，再上架。

## 搜索结果增强

在闲鱼当前搜索结果的全部商品卡片中持续补充：

- 想要人数与浏览次数
- 原始想要率（想要人数 ÷ 浏览次数）
- 经过小样本平滑后的可信等级
- 24 小时本地缓存和失败重试
- 想要数、浏览量、想要率的上下限即时筛选
- 排除小样本，并按想要率、想要数或浏览量排序
- 自动记住筛选条件，一键重置
- 独立“搜索”按钮，并支持在输入框按 Enter 执行
- 商品售价上下限、最低机会得分与“只看蓝海候选”筛选
- 机会得分：需求 25%、竞争友好度 25%、新卖家进入性 25%、供需缺口 15%、利润 10%
- 可配置单件成本、履约成本、退款/平台预留，展示预估净利润和利润率
- 发布时间起止范围与近 7 天、1 个月、3 个月快捷筛选
- 标题包含/排除词，避免无关商品污染市场判断
- 当前搜索市场快照与 CSV 分析导出
- 商品机会数据随官方搜索结果自动补充；条件筛选默认关闭，只有用户手动开启后才隐藏或排序商品
- 页面顶部持续显示发布时间条件及其“生效中/开启后生效”状态，刷新后保留快捷范围

机会得分达到 75 分只是第一层条件；同时还必须满足浏览量 ≥ 100、需求 ≥ 60、竞争友好度 ≥ 55、新卖家进入性 ≥ 55、利润率 ≥ 30%、单件净利润 ≥ ¥10，才显示“蓝海候选”。该标签用于缩小验证范围，不构成 7–15 天成交保证。

数据请求最多并发 2 个，并使用24小时本地缓存；滚动或站内换词后新增商品会自动进入队列。浏览量不足 100 时只显示“样本不足”，不会因偶然的高比例被标记为高潜。

## 本地开发

```bash
pnpm install
pnpm dev
```

WXT 会生成 `.output/chrome-mv3-dev`。在 Chrome 打开 `chrome://extensions`，启用开发者模式并选择“加载已解压的扩展程序”。开发进程运行期间，代码修改会自动热更新。

## 质量检查

```bash
pnpm check
pnpm zip
```

`check` 会依次执行类型检查、单元测试和生产构建。扩展安装包输出在 `.output`。

## 隐私与权限

- 数据默认保存在浏览器本地，不上传用户输入。
- 仅申请 `storage`、`sidePanel` 和闲鱼站点访问权限。
- 不使用远程脚本、`eval` 或动态代码执行。
- 在线演示仅用于体验界面，完整页面伴随能力需加载 Chrome 扩展。
